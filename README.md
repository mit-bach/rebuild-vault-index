# Rebuild Vault Index

Sidebar button that rescans hidden folders, refreshes the file tree, reindexes the metadata cache, and reloads community plugins. Use it instead of opening Nested Hidden Folders settings.

Open the pane from the ribbon (refresh icon) or the command **Open rebuild sidebar**. The pane is not opened automatically.

## Rebuild does

1. List hidden folders on disk.
2. Enable root dot-folders and nested `.grok` / `.pi` / `.v2`.
3. Reindex those enabled paths into the file tree.
4. Refresh File Explorer sort.
5. Reindex the metadata cache.
6. Reload every enabled community plugin except this one.

Disable Hidden Folders Access while Nested Hidden Folders is on.
